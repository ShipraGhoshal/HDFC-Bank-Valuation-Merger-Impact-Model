# HDFC-Bank-Valuation-Merger-Impact-Model
- Built an integrated financial model for HDFC Bank using historical trends and projected key drivers including loan growth, Net Interest Margin (NIM), operating costs, and profitability.
- Conducted detailed ratio analysis (ROE, ROA, Cost-to-Income, NIM, Loan-to-Deposit Ratio) to evaluate operational efficiency and financial performance.
- Performed Comparable Company Analysis (CCA) using peer banks to assess relative valuation and market positioning.
- Developed a proforma merger model by integrating standalone financials of Housing Development Finance Corporation and standardizing NBFC financials into a banking format.
- Analyzed post-merger impact on funding mix, NIM, LDR, ROE, and EPS, and compared pre-merger estimates with FY24–FY25 actual performance to assess synergy realization.
